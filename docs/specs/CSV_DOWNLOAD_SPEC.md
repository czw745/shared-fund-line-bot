# 短效 CSV 下載規格

## 目標

以 LINE 內的短效下載連結取代 Google Drive OAuth 與月底自動上傳，降低設定與維護成本。

## 行為

- `明細` 選單新增 `下載 CSV`。
- 下載內容為當月帳本，沿用既有穩定欄位與 UTF-8 BOM。
- 每次點擊建立不可猜測 token，連結有效 10 分鐘。
- URL 以既有 HMAC secret 簽章；token、到期時間或簽章不符時回覆 404。
- D1 只暫存 CSV 與檔名，排程清除到期資料。
- 不需要 Google OAuth、Drive API 或額外付費服務。

## 驗收

- LINE 選單能產生下載按鈕。
- 有效連結回傳 `text/csv` 與附件檔名。
- 無效或逾期連結無法下載。
- 完整測試與型別檢查通過。
