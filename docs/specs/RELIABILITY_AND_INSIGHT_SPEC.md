# 可靠性與洞察優化規格

## Flex 容量與分頁

- 最近紀錄、本月明細、修改交易每頁最多 10 筆。
- 超過一頁時顯示上一頁、頁碼、下一頁按鈕。
- Bubble JSON 上限 30 KB；Carousel JSON 上限 50 KB 且最多 12 個 Bubble。

## Flex 結構驗證

- 傳送前檢查容器類型、必要區塊、Carousel 數量與 JSON 大小。
- 不合法時自動退回純文字 fallback，避免 LINE 拒絕後完全沒有回覆。

## 已關帳交易

- 新增、修改、刪除已關帳月份交易均使用 Flex 確認卡。
- 顯示受影響月份與交易內容，提供確認／取消按鈕，不顯示內部確認碼。

## 本地消費洞察

- 程式計算本月支出、上月支出、最大分類、消費進度、月底預估支出與預估餘額。
- 洞察完全在 Worker 內產生，不將彙總財務資料傳送 Gemini。
- Gemini 仍僅用於既有的自然語言交易解析。
