# Flex 內容優化規格

- 高額／待入帳確認：欄位化顯示交易內容，高額交易加上警示標示。
- 多筆輸入有未辨識分類時，先只顯示並醒目標示目前需要處理的交易，分類按鈕使用「大分類／小分類」完整名稱；未完成分類前不顯示確認入帳。若有多筆待分類則逐筆處理，全部完成後才顯示整批確認頁。
- 修改交易清單：單張直向清單，每筆使用獨立淺灰卡片；分類與金額為主資訊，日期與備註為次要資訊，刪除操作使用警示色。
- 最近紀錄：依日期由新到舊分組，同日依最新流水號在前，收入與支出金額以不同顏色呈現。
- 本月明細：共用最近紀錄的日期標題、交易列、金額顏色與記錄者樣式；同日仍維持原輸入順序。
- 重複存入：同時顯示原存入金額與本次存入金額，再讓使用者選擇取代或額外補入。
- 全部訊息保留純文字 fallback，既有 postback 指令維持相容。
